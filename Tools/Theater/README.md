# 映画館のモデル（Blender）

アプリの映画館（`TheaterPlayer/Resources/Theater/Theater.usdz` と `TheaterLayout.json`）は、すべてこのフォルダの Python のスクリプトから作っています（手作業の修正はありません）。
Blender を画面なしで起動して流します。Blender 5.2 で確かめています。

## 作り方

```bash
Tools/Theater/run.sh build_theater.py --preview
```

```bash
Tools/Theater/run.sh export_theater.py
```

1. `build_theater.py`：映画館を組み立てて `out/theater.blend` と `out/layout_blender.json` を書きます。`--preview` を付けると、座席からの見た目を Cycles で描きます（`out/preview_*.png`。客電を点けた開場の状態と、上映中の状態）
2. `export_theater.py`：照明を Cycles（GPU）で焼き付け、アプリに入れる USDZ と配置の JSON を書きます（M4 Max で約 75 秒）。`TP_FAST=1` を付けると画像を 1/4・サンプル数 32 にして速く試せます（アプリの素材は書き換えず、`out/fast/` に書きます）

`out/` は git に入れません（作り直せるため）。

### RealityKit で確かめる

アプリと同じ `TheaterScene`（照明の状態・座席の組み立て・マスキング）を使って、macOS の RealityKit で座席からの見た目を描きます。

```bash
swift run -c release --package-path Tools/Theater/RKPreview RKPreview TheaterPlayer/Resources/Theater Tools/Theater/out/rk
```

上映中の画は、スクリーンに試しの夕焼けの絵を貼り、その色で部屋を照らした状態です。
`*_open` はアプリの開場（客電 3。環境変数 `RK_HOUSE` で変えられる）、`*_open_before` は以前の既定（客電 0.8）です。

## 映画館の作り

部屋は 26 m × 28 m、天井 15 m の大スクリーンの劇場です（`tp/config.py` に寸法と配置をまとめています）。

| 部分 | 内容 | スクリプト |
| --- | --- | --- |
| スクリーン | 半径 50 m の曲面。映像の最大は 21 m × 10.5 m（2.0:1）。上下左右の黒いビロードのマスキング（アプリが映像の縦横比に合わせて動かす）、袖幕、上の幕 | `tp/room.py` |
| 舞台 | スクリーンの前の低い台。黒いカーペット、吸音布の前面（奥にサブウーファー）、黒い布で包んだ鼻先（光る物は付けない。スクリーンの下に線として見えて映像の邪魔になるため） | `tp/room.py` |
| 客席 | スタジアム形式の 13 列（A〜N。I は使わない）× 34 席（左 8・中央 18・右 8）＝ 442 席。前の 3 列はゆるい段、D 列からは 0.45 m ずつ上がる | `tp/seats.py` |
| 座席 | 赤いビロードの座面・リクライニングした背もたれ（背の後ろも布張り）・背の天板・肘掛けとカップホルダー・背の後ろの真鍮の席番号の板・通路側の袖（足元灯と列の文字の板）。LOD0〜2 | `tp/seats.py` |
| 通路 | 壁ぞい 2 本とブロックの間 2 本。1 列に 2 段の階段、段鼻のアルミと LED の足元灯 | `tp/room.py` |
| 壁 | 腰板（ウォールナット）・吸音パネル・木のフィン（縦の LED の溝と、上下から壁を洗う光）・手すり。前方の左右に非常口（両開きの扉・押し棒）と避難口誘導灯 | `tp/room.py` |
| 天井 | 黒い天井と、15 枚の浮き天井（クラウド）。クラウドに埋め込んだダウンライト 60 灯（白い化粧枠・反射板・レンズ）と、クラウドの上の間接照明 | `tp/room.py` |
| スピーカー | 側壁のサラウンド 7 台ずつ、後ろの壁 4 台、天井 8 台。黒い塗装のキャビネット・パンチングメタルのグリル・ロゴの板・コの字の金具とつまみ・壁への腕と受け板。スクリーンの裏の L / C / R とサブウーファーは見えない位置だけ | `tp/speakers.py` |
| 映写室 | 後ろの壁の 3 つの映写窓（中央は映写機のレンズ。映像の明るさで光る） | `tp/room.py` |

素材の画像（カーペットの柄・ビロード・織物・木目・パンチングメタル・誘導灯の表示・席番号の板）は `tp/textures.py` が numpy で作ります（継ぎ目の出ない周期的なノイズ）。

## 照明の焼き付けと、アプリでの調整

照明は 3 つの層に分けて焼き付けます（`export_theater.py`、`tp/bake.py`）。

| 層 | ライト | アプリでの変わり方 |
| --- | --- | --- |
| 客電（house） | ダウンライト・クラウドの間接照明・壁を洗う光（208 灯） | 明るさの調整。開場（再生していないとき）は焼き付けたときの 3 倍（白のまま）で明るく、再生を始めると約 6 秒で落ち、止めると戻る。暗くするほど電球のように暖かい色に |
| 常時灯（ambient） | 通路の足元灯・袖の足元灯・誘導灯・映写室の薄明かり（177 灯） | 明るさの調整 |
| スクリーン（screen） | スクリーンの左・中央・右の 3 区画を光る面にして、それぞれの照らす量を r・g・b に入れる | 映像の 3 区画の色で、部屋が照らされる（映像に合わせて毎フレーム） |

- 建築は 1 枚のライトマップ（2048 px）に、座席は単位（座席＋肘掛け）ごとのマス（22 × 22）に焼きます。客席の床は段を 1 つの島に広げて詰めています
- マテリアルは照明を焼いた unlit の MaterialX（`ND_realitykit_unlit_surfaceshader`、トーンマップなし）です。`色 × Σ(層の光 × 層の明るさ) ＋ 発光 × 層の明るさ` を計算します
- 層の明るさ・区画の色は、すべてのマテリアルが共有する 8 × 1 画素の画像（入力 `lightState`）から読みます。アプリはこの入力を `LowLevelTexture` に差し替え、GPU で毎フレーム書き換えます（マテリアルは付け直しません。`Packages/TheaterCore/Sources/TheaterScene/LightingState.swift`）
- ライトマップは暗い所の階調を残すため √(光 ÷ k) を 8 bit の sRGB で入れ、シェーダーで 2 乗して k を掛けます

## 座席の組み立て（アプリ側）

USDZ には座席のひな形（Unit・UnitEnd・EndL × LOD0〜2 を、部品とマテリアルごとに分けた物）だけを入れ、アプリの起動時に `TheaterLayout.json` の単位の一覧からまとまり（列 × ブロック）ごとのメッシュを作ります（`SeatMeshBuilder`、`LowLevelMesh`）。
UV1 は単位のマスへ、席番号・列の文字の板の UV0 は番号の画像のマスへ移します。座る席からの距離で、まとまりごとに LOD を選びます。
こうして USDZ を小さく（座席をすべて入れると 58 MB → 約 30 MB）しています。
